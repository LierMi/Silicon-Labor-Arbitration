# 硅基劳动仲裁院 · 视觉灵感与 3D 方案

> 给 Eleven 的创作简报
> 版本：2026-07-29
> **色彩不预先规定明暗**，六个气质方向自选；3D 给了优先级和降级保险。

---

## 一、定调：我们要的是什么气质

一句话：

> **一份归档完好、编号齐全、却始终没有署名的责任。**

我们不是在做"法庭"，是在做**卷宗**。卷宗的美感来自秩序——编号、页码、装订、骑缝——而它的恐怖也来自秩序：**所有东西都在，唯独没有人。**

### 必须避开

- ❌ 赛博朋克 / 霓虹 / 故障艺术 —— 全场至少十个项目长这样
- ❌ 蓝紫渐变 + 发光线条 + 粒子背景 —— web3 默认皮肤
- ❌ 机器人拟人形象 —— 我们讨论的不是"AI 像不像人"

---

### 司法符号（天平 / 法槌）：可以用，而且应该用——但不能当图标用

天平和法槌本身没有问题，**俗的是"居中、金色、渐变、完整、对称"的那个版本**。
只要满足下面任意一条，它们立刻从图标变成作品语言：

**① 让它失去功能**

> **一架永远无法静止的天平。**
> C4 不可裁决时，天平停在倾斜状态、极轻微地震颤、始终不落定。

这和悬停的印章是**同一个动作的两个声部**——一个悬在空中，一个摆动不停，说的都是"判不了"。

> **一个缺席的法槌。**
> 桌面上有槌座（sound block），但槌不在。
> "我们不出判决"这句话，用一个空槌座说，比用任何文案都狠。

**② 让它失去完整性——极端裁切**

只出现天平的一端、一根横杆、一条悬链、槌柄的一段。**局部永远比全貌有力。**

**③ 让它失去尺度——极端放大**

一根巨大的、超出画幅的天平横杆，直接充当页面的结构线（页眉线、分割线、装订线）。它不再是"图案"，而是版式本身。

**④ 让它变成度量工具，而不是象征**

天平的刻度直接变成 C1–C4 的条款标尺；法槌只以**影子**的形式落在纸面上，本体从不入画。

**⑤ 让它只在交互中出现**

hover 时法槌缓缓抬起，松手后缓慢回落原位——**永远不接触桌面**。静止截图里它甚至不存在。

> 一句话原则：**这些符号可以是主角，但不能是装饰。**
> 判断标准很简单——如果把它删掉，画面只是少了一个装饰，那它就是俗的；如果删掉之后意思就不成立了，那它就是对的。

## 三、文学参考（拿什么，说清楚）

| 作品 | 拿什么 |
|---|---|
| **卡夫卡《在法的门前》** | ⭐️ 核心母题。一个人一生等在法的门前，守门人只说"现在还不行"。**这就是我们的空章位——永远无法抵达的那一次裁决。** |
| **卡夫卡《审判》** | 阁楼上的法院、堆到天花板的卷宗、无限延展的程序。空间感与压迫感 |
| **汉娜·阿伦特《艾希曼在耶路撒冷》** | ⭐️ 思想内核。每个人都只是执行上游指令，于是无人担责——**这本书就是"责任消失"的原典**。它的气质是冷静的、不煽情的、报告式的，我们的视觉也应该是 |
| **博尔赫斯《巴别图书馆》** | 无限档案。所有可能的记录都存在，但你找不到你要的那一本。对应"证据都在链上，责任却找不到" |
| **博尔赫斯《论科学的精确性》** | 一张 1:1 的帝国地图。**完整还原 ≠ 理解**——这正是责任链的悖论 |
| **石黑一雄《克拉拉与太阳》** | AI 的第一人称：忠诚、认真、并且完全误解了任务。这是我们的"Agent 交付了一颗土豆"的情感底色 |

| **《布达佩斯大饭店》** | 公文、印章、火漆、粉色文件的物质质感 |
| **《记忆碎片》Memento** | 倒叙式的责任还原。宝丽来照片 + 手写批注 = 一种可迁移的证据呈现语言 |

## 五、艺术与设计参考

### 5.1 当代艺术（这一层决定作品有没有"气质"）

| 艺术家 / 实践 | 拿什么 |
|---|---|
| **Forensic Architecture** | ⭐️⭐️ **我们在做的事的艺术版本。**用建筑测绘、影像比对、时间轴对齐来重建事件、还原责任——**而且他们明确不做审判，只做证据呈现**。整套视觉语言（多轨时间线、图层叠合、标注系统、冷静到近乎无情的排版）可以直接学 |
| **Mark Lombardi** | ⭐️⭐️ **责任链可视化的艺术原型。**手绘的权力与资金关系网络图，铅笔细线、优雅的弧线、节点与箭头。他证明了"关系图"可以是**美的**，而不只是信息图。责任链如果要做成一张图，看他 |
| **Cornelia Parker《Cold Dark Matter》** | ⭐️ **3D 分层责任链的直接参考。**炸开的小屋碎片被细线悬吊重组，中心一盏灯，投出巨大的影子。"一个完整的东西被拆散并悬停在空中"——这就是我们的委托链 |
| **Christian Boltanski** | ⭐️ 匿名者的档案：旧衣堆、无名肖像墙、裸灯泡、铁盒。**他一生的主题就是"消失的人"**。我们的主题是"消失的责任"，气质同源 |
| **Taryn Simon《The Innocents》** | 被误判者的肖像，拍摄于他们"被指认犯罪"的现场。**司法误判 + 冷静的档案式摄影**，与我们的立场（不轻易定罪）直接呼应 |
| **Walid Raad / The Atlas Group** | 虚构的档案、伪造的历史文献、编号严谨的假证据。**关于"档案的可信度"本身**——正好是链上证据的哲学命题 |
| **On Kawara** | 日期绘画、《I Am Still Alive》电报、《I Got Up》明信片。**极致的记录即作品**。案件编号的序列本身就可以是一件作品，这是它的依据 |
| **Hanne Darboven** | 巨幅的数字/日期系统墙，成百上千张纸铺满整面墙。**"档案墙"如果要做，看她** |
| **Fischli & Weiss《事物的运行方式》** | 一连串因果反应，每个环节推动下一个，没有作者在场。**这就是委托链的影像原型**——每一步都只是"被上一步推动" |
| **Sophie Calle** | 侦探式取证、他人留下的痕迹、图文并置的叙述结构。取她"证据 + 叙述"的版面关系 |
| **Hans Haacke** | 制度批判：把机构的运作方式做成图表和文件。**冷静的呈现即批判**，不需要愤怒的语气 |

> 如果只看两个：**Forensic Architecture**（方法与视觉）+ **Mark Lombardi**（图形语言）。

### 5.2 平面与版式

- **Karel Martens**——套印、错位、印刷的偶然性。**"程序性的不完美"这条美学的源头**
- **Wim Crouwel / Massimo Vignelli**——网格系统、单一字体家族、克制到极致
- **Irma Boom**——书籍作为物件：厚度、切口、翻页节奏
- **Otl Aicher · 1972 慕尼黑奥运会**——冷静的符号学，极少色彩
- **Experimental Jetset**——用最少的元素做出最强的态度

### 5.3 现成的视觉系统（可直接借用）

- **法医证据摄影**——黄色 L 形证物编号牌、比例尺、冷光。**这套符号可以直接拿来标记 E1/E2/E3**
- **NTSB 空难调查报告**——多轨时间线对齐、"最后 30 秒"逐字稿排版
- **中国 80–90 年代公文**——介绍信、单位公章、复写纸、油印质感
- **日本判子文化**——印章的物质性、朱肉的质感、**盖歪一点点才真实**
- **工程爆炸视图（exploded axonometric）**——⭐️ 责任链 3D 化的直接图形来源
- **医学影像 / X 光片**——透明叠层、看穿结构

## 六、六个色彩气质方向（自选，不预设明暗）

| 方向 | 关键词 | 气质 | 风险 |
|---|---|---|---|
| **① 中式公文** | 宣纸白 · 印泥朱 · 墨黑 | 最贴"仲裁院"三个字，盖章语言天然成立 | 容易做土，版式必须极现代来对冲 |
| **② 法医冷白** | 冷白 · 证物黄 · 灰蓝 | 克制、专业、证据感强，编号系统好看 | 偏冷，情绪不足，需靠动效补 |
| **③ 机构绿（Severance 式）** | 米白 · 深松绿 · 终端绿 | ⭐️ 复古企业感，"硅基劳动"四个字的完美视觉 | 需要精准的字体选择，否则像老软件 |
| **④ 档案牛皮** | 牛皮 · 曝光旧纸 · 铁锈红 | 温度最高，物质感最强，适合做 3D 材质 | 容易过怀旧，失去"硅基"的当代感 |
| **⑤ 蓝图** | 普鲁士蓝 · 白线 · 少量橙 | 结构感极强，责任链画成工程图非常合适 | 信息密度高时易糊 |
| **⑥ 夜间档案室** | 深棕黑 · 单点暖光 · 朱红 | ⭐️ 唯一的暗色方向，戏剧性最强，3D 打光最出效果 | 与"卷宗"的纸感冲突，需要靠材质救 |

### 我的建议

**③ 或 ⑥ 二选一。**

- 选 **③ 机构绿**——赢在"硅基劳动"的概念契合度，白天感，冷静，适合大量文字信息
- 选 **⑥ 夜间档案室**——赢在戏剧性和 3D 表现力，单点光下的悬停印章会非常美

**不要在两者之间摇摆超过 D1。**D1 结束前必须定，因为 3D 的打光方案完全取决于这个选择。

## 七、2D 方案（基线，必须能独立成立）

**原则：3D 是加分项，2D 必须能单独撑起整个 demo。**

| 页面 | 2D 做法 |
|---|---|
| **责任链** | 竖向时间线，每一跳一张卡片。卡片四栏：**谁 / 什么授权 / 看见什么警告 / 做了什么**。用左侧连接线 + 编号标尺贯穿 |
| **裁决页** | 条款列表 C1–C4，每条右侧一个章位。盖章用 CSS `transform: scale() rotate()` + `filter: blur()` 阴影模拟落下 |
| **空章位** | 章停在上方，用 `box-shadow` 做悬空投影，章位留白 + 虚线框 + 小字「待人工复核」 |
| **AI 三路意见** | 三栏并置（罗生门式），每条结论后面挂 `[E1][E2]` 的证据角标，可点击高亮对应证据 |
| **案件大厅** | 档案卡网格，每张卡是一个卷宗封面：编号、状态标签、金额、日期 |

**2D 就能做到 80 分。3D 是从 80 到 95。**

## 八、3D 方案：哪里先上，ROI 排序

### 技术栈

```
React Three Fiber (R3F) + @react-three/drei
```

**不要用建模软件。**全部用基础几何体拼装（cylinder / box / plane / torus）+ 材质 + 光影。
**效果来自打光，不来自模型精度。**一盏 spotLight + `<ContactShadows>` 就能出彩。

路演是投屏，不用考虑低端设备性能。

### ROI 排序表

| 优先级 | 位置 | 3D 能给什么 2D 给不了的 | 成本 | 做不做 |
|:--:|---|---|:--:|:--:|
| **🥇 1** | **悬停的印章（空章位）** | **"悬停"的物理感**——章在空中、投下阴影、纸面空白。2D 永远做不出这个 | **0.5 天** | ✅ **必做** |
| **🥈 2** | **责任链分层堆叠** | 把"责任在链条中传递"变成**穿越**：每一跳是 Z 轴上一层半透明层片，相机沿 Z 推进，一层层穿过 | 1 天 | ✅ 做 |
| 🥉 3 | 并发大屏 | N 个案件在 3D 空间同时亮起，Monad 并行的空间化 | 1 天 | ⚠️ D4 后有余力 |
| 4 | 案件大厅的 3D 卷宗 | 可旋转的档案袋对象 | 1 天 | ❌ 砍 |
| 5 | 全站 3D 场景（虚拟仲裁院） | —— | 3 天+ | ❌ **绝对不做** |

---

### 🥇 第一落点：悬停的印章（半天，最高性价比）

**这是全项目最重要的一帧，也是 3D 成本最低的一处。**

```
C1 满足 → 印章下落 → 接触纸面 → 轻微下陷 → 油墨渗透 → 抬起 → 留下印记
C2 满足 → 同上
C3 满足 → 同上
C4 不可裁决 → 印章下落到一半 → 停住 → 微微颤动 → 停在空中
            → 纸面上只有一个影子，没有印记
            → 影子边缘随呼吸般轻微缩放
```

**技术拆解（都是基础件）：**

- 印章 = `cylinderGeometry`（章身）+ `torusGeometry`（握把）+ 顶面文字贴图
- 纸面 = `planeGeometry` + 纸张法线贴图
- 光 = 一盏 `spotLight` 斜上方 + `<ContactShadows>`
- 印记 = 落章瞬间在纸面 texture 上叠一层 decal（或直接切换贴图）
- 悬停的颤动 = `useFrame` 里给 y 轴加一个极小的正弦扰动

**为什么这是最高 ROI：**
它同时说完了立场（AI 不判）、差异（Internet Court 必出判决）、诚实（判不了就说判不了）。**一帧顶三句台词，而且它只要半天。**

---

### 🥈 第二落点：责任链分层堆叠（1 天）

灵感来源：**工程爆炸视图 + 《Devs》的因果可视化 + X 光透明叠层**

```
        人类的原始意图        ← 最前层，最清晰
              ↓ Z
        主 Agent 的转译       ← 半透明，文字开始偏移
              ↓ Z
        子 Agent 的执行       ← 更透明
              ↓ Z
        工具调用的参数        ← 几乎透明
              ↓ Z
        最终发生的交易        ← 最后层
```

**关键设计：越往后的层，透明度越高、文字与原意的偏差越可见。**用户滚动时相机沿 Z 轴推进，穿过每一层。

**"责任消失"不是被说出来的，是被看见的**——层与层之间的错位就是责任流失的量。

**技术拆解：**
- 每层 = 一个 `planeGeometry` + `meshBasicMaterial` (transparent)
- 文字用 `drei` 的 `<Text>` 或 HTML 贴图
- 相机推进 = `useScroll` + `damp` 平滑插值
- 层间连线 = `<Line>` from drei

## 九、3D 的降级保险（必须先写好）

**如果 D3 晚上 3D 没成型，立刻切到 CSS 伪 3D，不要恋战。**

| 3D 效果 | CSS 降级方案 | 成本 |
|---|---|---|
| 悬停印章 | `transform: translateZ()` + `box-shadow` 做悬空投影 + `@keyframes` 微颤 | 1 小时 |
| 分层堆叠 | 父容器 `perspective: 1200px`，子层 `translateZ(-100px * i)` + `opacity` 递减 | 2 小时 |
| 落章 | `scale(1.4) → scale(1)` + `rotate(-3deg)` + `filter: blur()` 阴影收敛 | 1 小时 |

**CSS 伪 3D 能做到真 3D 的 70% 效果，成本是 1/8。**先把降级版做出来当保底，再去做真 3D——不要反过来。

## 十一、让它真的有艺术气质的七个手法

好看的 UI 和有艺术气质的 UI，差别不在素材，在下面这几条。**都很便宜，最贵的一条也不到两小时。**

### ① 一个贯穿全场的物件，而不是一堆装饰

整个项目只需要**一个**主角物件——**印章**。天平、法槌、卷宗、编号牌全部是它的配角。
凡是不能服务于"章落不落得下去"的视觉元素，删掉。

> 装饰是加法，作品是减法。

### ② 敢留白

艺术气质有一半来自**空**。信息密度低到让人不安的程度，才会开始像作品。
裁决页上，四条条款和一个空章位，**周围应该有大片什么都没有的地方**。

### ③ 程序性的不完美 ⭐️ 最便宜的一条

```js
rotate: -3deg + random(-1.5, 1.5)      // 每次盖章角度都不同
opacity: 0.82 + random(-0.06, 0.06)    // 油墨深浅不同
offset: random(-2px, 2px)              // 落点微偏
```

**完美的重复是软件，微小的不完美是手工。**
Karel Martens 一辈子在做的就是这件事。这三行代码是整份文档里性价比最高的东西。

### ④ 不解释

界面上每少一句说明文字，气质就上一档。
不要写"这里显示 AI 的三方意见"——**直接把三段意见放上去，让人自己看懂**。
唯一值得留的文字是那句"待人工复核"，因为它是内容不是说明。

### ⑤ 序列即作品

案件编号、条款编号、证据编号——**把它们当成 On Kawara 的日期来对待**，而不是当成表格字段。
统一字号、统一间距、大量重复、绝不装饰。一列整齐的 `E1 E2 E3 …` 本身就很美。

### ⑥ 材质要有物理性

纸的纤维、油墨在纤维上的渗透、章身的磨损、影子的软硬。
**3D 的价值不在"立体"，在"有重量"。**一个有重量的章，落下时才有分量；悬停时才有悬念。

### ⑦ 声音（如果还有时间）

一次盖章的闷响。**只做这一个音效，别的都不做。**
路演现场那一声，加上 C4 时那一声**没有响**——安静本身会成为全场最响的一下。

## 十二、节奏与戏剧性：偷游戏的剪辑语法，不偷画风

### 原则

**档案的皮肤 + 游戏的节奏。**

静态截图上档案感更高级，但**动态演示如果不做节奏设计，就是一份会滚动的 PDF**。所以要向游戏偷东西——只是偷**剪辑语法**，不偷画风。

### 为什么不做逆转裁判的画风（三条，第三条是决定性的）

1. **画风会和主张打架。**逆转裁判的美学内核是**确定性**——法槌一定落下、真凶一定被戳穿。而我们的立场是**判不了就说判不了**。视觉是先于台词被接收的，用"一定有答案"的语言讲"我们拒绝给答案"的产品，评委会本能地觉得不对劲。
2. **会被读成玩笑。**动漫立绘 + 对话气泡会把评委的第一判断推向"搞笑项目"，抵消掉我们建立的严肃感。
3. **7 天内没有插画产能。**逆转裁判的全部力量在角色立绘的表情。没有立绘就只剩速度线和大字——那是它最廉价的部分。AI 生成的动漫角色，廉价感一眼看穿。
   **而档案感零插画**：字体、材质、编号、3D 基础几何体，全部可以靠工程手段做到高完成度。这对我们的产能结构是决定性优势。

> 改口的唯一条件：队里有人能在三天内画出 3–4 张达到发布水准的立绘。没有的话，半成品立绘比没有立绘糟糕得多。

### 游戏参考（每个说清楚拿什么）

| 游戏 | 拿什么 |
|---|---|
| **《Papers, Please》** | ⭐️⭐️ **机制上最贴的一个。核心动作就是盖章**——规则比对、文件叠放、章落下的重量感、桌面即界面。而且它的主题是"按规则执行的人的道德困境"，和平庸之恶同源。**盖章手感直接参考它** |
| **《Return of the Obra Dinn》** | ⭐️⭐️ **归因机制的游戏原型。**你要还原每个人怎么死的、谁做的——**这就是责任归因**。关键设计：游戏只在你填对三个时才确认，**填不出来它就让你悬着**，绝不提示。这正是我们的 `undecidable` |
| **《逆转裁判》** | ⭐️ 剪辑语法：停顿→放大、异议爆发、一跳一顿的推进、左右对峙构图。**拿节奏，不拿画风** |
| **《极乐迪斯科》Disco Elysium** | ⭐️ **多声部辩论 = 我们的三路 AI 意见。**它把不同的"技能"写成互相反驳的独立声音，各有立场和语气。检方/辩方/审计的文案语气可以照这个写 |
| **《The Case of the Golden Idol》** | 填空式归因：把姓名、动作、动机拖进句子的空格里。**"责任归因"的交互原型**，比自由文本高级得多 |
| **《Her Story》/《Immortality》** | 证据检索式叙事，玩家自己拼真相，**游戏从不给结论**。立场同源 |
| **《底特律：变人》** | 每章结束的**分支流程图**——已走过、未走过、他人选择的比例。责任链如果要做分支可视化，看这个 |
| **《1984: Orwell》** | 你提交的证据决定别人命运。**"提交证据"这个动作的重量感**怎么做，看它 |
| **《疑案追声》Unheard** | 多条声音时间线并行，同一时刻不同房间发生的事。**多轨时间线的对齐方式**可参考 |

> 只看两个：**Papers, Please**（盖章与桌面）+ **Obra Dinn**（归因与悬置）。

### 逆转裁判手法 → 档案版对照

| 原手法 | 我们的用法 |
|---|---|
| 停顿 → 突然放大 | C4 那一刻：**全部动效停住，镜头推近空章位，2 秒不动** |
| 「異議あり！」爆发 | **一枚朱红「异议」戳「啪」地砸在纸面上**，纸张震一下 |
| 画面震动 + 速度线 | 震的是**纸和章**，不是人物；速度线用**装订线与标尺的位移**代替 |
| 一跳一顿的对话推进 | 责任链**不做平滑滚动**——一跳一顿，每跳后停 0.3 秒 |
| 左右分屏对峙 | 三路意见用**文书分栏**对峙，不用立绘 |
| 音效 | 只做一个：**盖章的闷响**。C4 时那一声不响 |

### ⭐️ 最该偷的一个动作：甩证据

逆转裁判最爽的一秒，是**把一份证物摔到对方脸上**。

而我们的产品核心恰好就是证据和引用——AI 意见里的 `[E2]` 角标。

**不要做温和的高亮。**点击 `[E2]` 时：

```
证物从侧面弹进画面中央 → 轻微过冲 → 停住 → 纸面震一下
```

一个交互就把那份快感拿到了，**成本不到两小时，而且完全没有离开档案美学。**

### C4 那一刻的完整分镜（照着做）

```
0.0s   C3 盖章完成，墨迹在纤维上渗透
0.4s   ── 静止。什么都不发生。这 0.4 秒非常重要 ──
0.6s   印章升起，横移到 C4 位置
1.2s   开始下落
1.6s   下落到一半 —— 停住
1.7s   极轻微的颤动（2–3px，频率要慢）
2.0s   镜头缓慢推近（scale 1.0 → 1.08，缓动越慢越好）
2.4s   音效全部静音；纸面上只剩一个影子
3.0s   「待人工复核」淡入（淡入，不要滑入）
3.5s   人类终审按钮出现
```

**全场最强的一刻，是最安静的一刻。**

---

### 节奏的三条通则

1. **顿比动重要。**每个关键动作之后留 0.3–0.5 秒什么都不做。新手都在加动效，高手在加停顿。
2. **一次只动一个东西。**同时有两个元素在动，冲击力就归零了。
3. **高潮靠减法。**C4 的力量不来自加了什么，来自**声音没响、章没落下、页面没往下走**。
