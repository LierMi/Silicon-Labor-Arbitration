## 三、ResponsibilityChain3D 接入边界

正式模型到位前不增加 `three`、React Three Fiber 或 Drei 依赖，也不在公开演示中展示临时几何白模。

首个落点固定为第三幕“归因”：

```text
人类委托
  -> 钱包签名前边界
  -> 主 Agent 转译
  -> 工作 Agent 执行
  -> 工具交付
```

3D 只负责空间化呈现，不成为新的事实源。组件继续消费现有 typed fixture 中的 `responsibilityChain` 和 `evidenceRefs`，点击节点仍由现有证据抽屉展示原始证物。

预期组件边界：

```ts
type ResponsibilityChain3DProps = {
  hops: Case["responsibilityChain"];
  focusedEvidenceId: string | null;
  onFocusEvidence: (id: string | null) => void;
  onOpenEvidence: (id: string) => void;
};
```

模型最低要求：

- GLB 或 glTF 2.0。
- 证据板、钢丝或挂钩、责任节点和断链位置可以独立寻址或分组。
- 材质符合暗场法庭、冷蓝透明证据板、焦黑碎片和单点暖光语言。
- 交付前完成贴图压缩和面数优化；总体积目标不超过 5 MB，超出时必须先评估加载成本。

## 四、性能与视觉门槛

第三幕 3D 必须通过以下门槛后，才讨论扩展到开屏、法庭总览或其他幕次：

- 只在进入第三幕时动态加载，不增加开屏首包中的 Three.js 成本。
- 离开第三幕后暂停渲染，页面隐藏时停止动画循环。
- 使用容器尺寸和 `ResizeObserver`，不直接依赖全局窗口尺寸。
- DPR 设置上限，并为移动端提供 2D 责任链降级。
- 支持 `prefers-reduced-motion`，降级时展示稳定的静态构图。
- 用真实设备或浏览器性能记录验证帧率、加载时间和内存；不使用未测量的性能宣传数字。
- 视觉上必须让“责任在委托链中变薄”比现有 2D 更清楚，否则保留 2D，不为 3D 而 3D。

## 七、3D 试验素材归档（不进入运行时）

记录日期：2026-08-07。

### 已验证：Hanging Industrial Lamp

- 用户提供原包：`hanging_industrial_lamp_4k.blend.zip`，约 115 MB。
- 来源：[Poly Haven · Hanging Industrial Lamp](https://polyhaven.com/a/hanging_industrial_lamp)。
- 作者：Kuutti Siitonen。
- 许可：CC0。
- 试验文件：`apps/web/public/models/hanging-industrial-lamp-1k.glb`，当前页面不加载。
- 网页体积：641,780 bytes，低于 5 MB 门槛。
- SHA-256：`b828ba9909d6c0773864bc8fe058f053e0d8b55d93b005f0e394ba00ac3718b2`。
- 几何：8,662 个上传顶点，9,204 个三角形图元。
- 转换：官方 1K glTF 依赖经 glTF Transform 合并为单一 GLB，纹理转换为 WebP，几何使用 glTF 原生量化。
- 校验：glTF Validator 无错误；原模型缺少显式 tangent，保留运行时 tangent-space 生成警告，避免写入无效切线数据。

最终决策：吊灯和 WebGL 场景不进入第三幕。模型仅作为试验记录保留，页面运行时不下载、不解析、不渲染该 GLB。

### 暂缓接入

- `modular_electricity_poles_4k.blend.zip`：约 201K tris，1K glTF 的几何与贴图仍明显超出本幕收益；其中电缆、绝缘子可在后续离线拆件减面后重新评估。
- `rusted_wheel_rim_02_4k.blend.zip`：约 15K tris，但当前没有直接对应责任节点、证据或仲裁边界的语义；直接放入只会形成废墟装饰，因此不接入。

### 最终实现边界

- 不依赖 R3F、Drei 或 Three.js，不创建 Canvas，也不检测 WebGL。
- 五个责任节点使用 2D 横向等距布局，冷蓝表示可追溯链路，朱红表示意图偏移。
- 鼠标悬停、键盘聚焦或选中节点时，卡片放大、提亮并保持证据联动。
- 移动端改为可横向滚动的证据板；`prefers-reduced-motion` 继续遵循全局降动效规则。
