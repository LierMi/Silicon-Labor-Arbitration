# 硅基劳动仲裁院 · 仲裁庭总览页设计规格

日期：2026-08-06
状态：已批准（用户选择方案 A）

## 1. 页面位置

体验路径固定为：

`爆炸画廊开屏 / → 仲裁庭总览 /courtroom → 六幕案件 /demo`

开屏的主按钮不再直接切换到六幕，而是进入独立仲裁庭页面。仲裁庭承担“制度空间与案件全貌”的第二幕；六幕继续承担逐证据、逐条款的深入阅读。

## 2. 设计原则

- 遵循 `docs/03-视觉灵感与3D方案.md`：档案的皮肤，游戏的节奏。
- 借用《逆转裁判》的剪辑语法，不借用动漫画风。
- 法院符号必须参与叙事：法槌代表待定裁决，天平代表无法稳定的 C4，而不是装饰图标。
- 页面主色延续开屏的夜间档案室：近黑、冷蓝玻璃、骨白文字、少量证物黄与异议朱红。
- 保留大量暗场空间，避免把参考图机械复刻成密集仪表盘。

## 3. 页面构图

### 顶部机构栏

- 左侧：`SLA` 文字标识。
- 主名称：`硅基劳动仲裁院`。
- 英文：`SILICON LABOR ARBITRATION`。
- 右侧：案件编号与链状态。

### 中央仲裁庭

- 使用用户素材中的真实法院空间图作为全屏背景，经暗化、冷蓝染色和局部聚光处理。
- 中央保留“无人认领”的空位与审计席，不放拟人机器人。
- 左右两侧分别是主张与抗辩文书，形成对峙构图。
- 三路意见以文书/证物板出现，不使用角色立绘。

### 左侧案件卷宗

- 案件编号、争议金额、当前状态。
- 六步仲裁进度，当前步骤停在 AI 多方意见。
- 框体使用透明冷蓝证物板，延续开屏视觉语言。

### 右侧确定性规则

- C1–C3 显示已满足。
- C4 显示无法锁定责任主体。
- C4 是唯一异议爆发点；点击后画面停顿、放大，并落下一枚朱红“异议”章。

### 底部责任链与证据

- 责任链以五个节点横向排列。
- 节点按“一跳一顿”顺序点亮，不使用连续流光。
- E1/E2/E3 以冷蓝证物卡呈现；点击时从侧面甩入中央，轻微过冲后停住。
- 主操作进入 `/demo`，查看现有六幕案件。

## 4. 动效分镜

1. 背景从黑场缓慢显影并轻微推近。
2. 左右文书分别从画面两侧进入，中央审计席最后出现。
3. 责任链逐节点推进，每跳停顿约 0.3 秒。
4. 点击证物：证物侧向弹入 → 过冲 → 停住 → 纸面轻震。
5. 点击 C4：其他动效停止 → 画面推近 → “异议”章落下 → 章悬停在裁决位上方 → 显示“待人工复核”。
6. `prefers-reduced-motion` 下取消位移、震动与连续颤动，仅保留淡入和状态切换。

## 5. 素材使用

首版只使用用户提供的现成素材，不生成新图：

- `0e4729093d49f08d22b28d57673fae45.jpg`：法院空间背景。
- `04aa89bc8cb17f0e66e55ff88c373dc7.jpg`：悬浮法槌与文件，用于人类终审区域或裁决视窗。
- `9e494257b3c70a652c104a66188fb077.jpg`：实际交付的土豆证物。
- `8d795b8952fc1f107796846dfd937cf8.jpg`：争议预期的卡通土豆证物。
- `a6add09b322cf78e304c6cc4b8b374d7.jpg`：正义女神，仅允许局部极端裁切，不作为完整装饰图。

不使用 `a88d...`、`b4ed...` 等明显动漫法庭素材，避免偷取《逆转裁判》的画风。

## 6. 品牌标识

产品标识采用参考图左上角的组合结构：

- 主标识：`SLA`。
- 中文全称：`硅基劳动仲裁院`。
- 英文全称：`SILICON LABOR ARBITRATION`。

首版用排版标识实现，确保在不同分辨率上清晰；不从参考截图低清裁切 Logo。

## 7. 响应式与可访问性

- 桌面端以单屏剧场构图为主。
- 1024px 以下将侧栏折叠为上下信息带，保持中央庭审空间。
- 767px 以下改为纵向案件总览，避免缩小桌面仪表盘。
- 证物、规则和主操作均可通过键盘访问。
- 所有图片提供替代文本；文字对比满足暗色背景可读性。

## 8. 验收标准

- `/courtroom` 为独立路由，开屏主按钮进入该页。
- `/courtroom` 主操作进入 `/demo`，六幕内容保持可用。
- 页面显示 SLA 中英文组合标识。
- C1–C4、责任链和 E1–E3 在首屏内形成清晰信息层级。
- C4 具备停顿、推近、异议爆发和待人工复核状态。
- 证物具备侧向甩入交互。
- 未生成任何用户未提供的司法素材。
- 生产构建、桌面与移动端视觉回归通过。
