# 展示级修复设计

## 目标

在不等待新素材的前提下，把现有三段体验修到可诚实路演：开屏负责建立命题，法庭总览负责说明争议，六幕案卷负责展示可复算证据、规则边界和人工复核。

## 不可变约束

- 保留用户已经确认的主体文案和 SLA 品牌。
- C4 始终为 `undecidable`，系统不制造自动终局判决。
- 未广播的交易不得写成已上链、已锁定或已确认。
- 缺少原始猫图和原始透明 PNG 时，保留清晰的证物待补状态，不用替代图片冒充。
- 1280x720 是首要路演视口，正文目标不低于 14px，关键正文目标为 16px。

## 数据与证据

- 全部时间从 fixture ISO 时间生成，并明确使用北京时间。
- 删除 E2 非法占位哈希；原始交付文件到位后再写入真实哈希。
- 增加 E4 主 Agent 转译日志和 E5 工具调用/警告日志，让意图漂移和风险忽略有直接证据。
- 钱包节点只陈述签名前核对边界，不声称本案已经签名或广播。
- 将责任链按真实事件时间排序，并把“执行责任链”与“链上技术路径”分开。

## 交互与信息架构

- `/` 进入 `/courtroom`，`/courtroom` 进入 `/demo`，六幕 Logo 返回 `/courtroom`，不在 `/demo` 内嵌开屏。
- 证据抽屉或终审弹窗打开时禁用换幕滚轮和方向键。
- 六幕状态写入 URL hash，刷新和分享可保留当前幕。
- 人工复核结果本地持久化，并明确标注“本地归档意见、未签名、未广播”。
- 人工复核增加复核人名称和角色，不把匿名点击伪装成合法终审。

## 视觉

- 法庭总览减少同屏小字，提高面板不透明度与正文尺寸。
- 技术链从八个等宽卡片调整为两条有方向的轨迹：授权/资金路径与执行/责任路径。
- 第一幕提前显示 C4 为核心条款及其全额冻结后果，避免事后改变规则的观感。
- 新素材未到前，交付图明确标注为“预览副本，不用于验证 PNG/alpha”。

## 验证

- 领域校验器拒绝非法证据哈希。
- 测试确保时间展示来自 fixture，而非硬编码。
- Web typecheck、domain tests、production build 全部通过。
- 浏览器复测 `/`、`/courtroom`、`/demo`、技术链、证据抽屉与人工复核。
