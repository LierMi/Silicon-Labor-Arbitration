# 爆炸画廊开屏页视觉改造设计

日期：2026-08-06
范围：`apps/web` 开屏页（`Landing`）

## 目标

把现有暗房式开屏升级为“责任爆炸被暂停”的黑盒画廊装置。页面需要在三秒内建立两件事：所有证据完整存在，责任中心却无人认领。

本次只修改视觉表现和交互表现，不修改任何现有可见文案、案件数据或进入六幕体验后的业务逻辑。`Landing` 中现有中文、英文、按钮文字、案件编号、链上信息和证据内容必须逐字保留。

## 采用方案

使用“电影级背景底片 + DOM 证据层 + GSAP 动效”的混合方案。

- 背景底片负责黑盒展厅、爆炸残骸、裸灯泡、烟尘、地面与墙面阴影等摄影级空间质感。
- DOM 负责所有现有文字、E1/E2/E3 证据板、吊牌、中心责任落点、导航、按钮和实时案件数据。
- GSAP 负责首入时间轴、鼠标视差、证据悬停和进入案件时的镜头推进。
- CSS 提供背景图缺失时的暗场降级，并承担静态材质、响应式和 reduced-motion 样式。

不直接把参考图作为页面背景，因为参考图内已经烤入导航和文字；也不采用全场 React Three Fiber 重建，因为当前开屏所需的视觉收益不足以覆盖实现和性能成本。

## 视觉构图

保留现有信息结构和文案位置的基本逻辑，但重新建立层级：

1. 左侧文案是可读层，约占桌面宽度的三分之一。使用深色渐隐保护区确保主标题和段落在复杂背景上仍清晰。
2. 中央偏右是视觉主场：裸灯泡照亮环状爆炸残骸，中央保留明显空洞，现有“责任落点 / 无人认领”位于空洞内。
3. E1/E2/E3 透明证据板分布在残骸前后景，位置避免遮挡左侧文字和中心空洞。
4. 工具参数、钱包签名、翻译日志和断链警告使用更小的悬吊标签，形成第二信息层。
5. 顶栏与底栏保留全部现有内容，仅改善对齐、对比度、间距和展陈式细线结构。

色彩使用近黑、骨白、焦炭灰、证据黄、灼烧橙和少量冷蓝玻璃反光。现有朱红从主导色降为局部事故标记色，避免重新回到夜间卷宗或司法机构视觉。

## 视觉资产

以用户提供的两张 1672 × 941 参考图为构图和材质依据，制作一张新的无文字、无导航、无证据牌 UI 的 16:9 背景底片。底片必须保留：

- 黑盒画廊空间；
- 中央裸灯泡或冷暖中性的单点光源；
- 环状炸开的烧焦木片、碎纸、线缆、金属件和烟尘；
- 中央清晰的空洞；
- 地面与后墙上被放大的真实投影；
- 左侧足够暗且相对安静的文字安全区。

背景资产存入 `apps/web/public/images/`，使用 WebP 或 AVIF 主版本，并保留合理质量的降级格式。网页不依赖参考图中已有的任何文字。

## 组件边界

开屏逻辑保持在现有页面架构内，但将视觉职责拆成小型组件或数据层：

- `Landing`：控制进入案件状态、指针坐标和顶层可访问性。
- `GalleryBackdrop`：背景底片、暗角、光束、颗粒、烟尘和地面光。
- `EvidenceRig`：E1/E2/E3 证据板与悬吊结构。
- `DebrisField`：程序生成的近景碎片，只作为景深补充，不冒充摄影主体。
- `ResponsibilityVoid`：中央空洞、准星和现有责任落点文案。
- `LandingCopy`：原封不动渲染当前文案与按钮。

组件可在同一文件中实现；只有当 `page.tsx` 因开屏改造继续明显膨胀时才拆文件。本次不做与开屏无关的重构。

## 动效时间轴

首入动画总时长控制在约 1.8 秒：

1. 暗场显影，灯泡亮起，背景底片由低曝光恢复。
2. 证据板和近景碎片从中心沿各自方向轻微散开并迅速减速，形成“爆炸被暂停”，不是持续漂浮的粒子效果。
3. 中心空洞准星与文字显影。
4. 左侧文案、顶栏、底栏最后进入，确保视觉先建立、信息随后可读。

指针移动只产生小幅视差：背景、摄影底片、碎片、证据板按不同深度移动，最大位移受限，避免晕动和廉价跟手感。证据板悬停时前移、提高反光和清晰度，其他证据轻微降暗；键盘聚焦获得相同状态。

点击任一现有进入按钮后，中心区域放大、暗场曝光提高并淡出，再调用当前 `onEnter`。保留现有 620ms 左右的状态切换节奏，必要时仅为 GSAP 时间轴调整到相近时长。

## 响应式与无障碍

- 桌面以 16:9 路演画面为主，重点验证 1280 × 720 和 1672 × 941。
- 768–1024px 保留背景底片，缩减近景碎片数量并收紧证据板尺度。
- 小于 768px 时使用固定裁切的底片，隐藏次要吊牌和部分碎片，证据板退到背景层，确保原有文案与按钮完整可读。
- `prefers-reduced-motion: reduce` 下取消爆炸展开、持续晃动和指针视差，只保留短淡入。
- 交互证据板使用可聚焦元素或等效语义，保持可见焦点；装饰碎片不进入辅助技术读取顺序。
- 图片加载失败时，CSS 暗场、灯光和 DOM 证据板仍能构成可用首屏。

## 性能与失败处理

- 背景底片按桌面与移动端提供合适尺寸，避免直接发送原始超大 PNG。
- GSAP 只修改 `transform`、`opacity` 和必要的滤镜；不在指针事件中触发 React 高频重渲染。
- 动画初始化在客户端作用域内完成，卸载时清理 timeline、监听器和 matchMedia 上下文。
- 页面在 GSAP 加载失败或 JavaScript 禁用时仍显示完整静态开屏。

## 验收标准

- 所有当前可见文案逐字不变。
- 3 秒内能从画面读出“证据围绕中心存在，但责任中心缺席”。
- 首屏在 1280 × 720 和 1672 × 941 下无文字遮挡、无横向溢出、无关键对象被裁掉。
- 进入案件按钮、证据板焦点状态和 reduced-motion 行为可用。
- 背景底片加载前后没有明显布局跳动。
- `pnpm --filter @sla/web typecheck` 与 `pnpm --filter @sla/web build` 通过。
- 浏览器控制台无新增错误，进入六幕体验的现有流程不回归。

## 明确不做

- 不修改文案、业务数据、案件故事或六幕内容。
- 不把参考图中烤入的文字直接带进页面。
- 不引入全场 3D 引擎。
- 不扩展到开屏之后的 UI 重做。
- 不增加与当前叙事无关的导航、说明段落或功能入口。
